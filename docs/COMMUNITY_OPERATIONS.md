# 신고 처리와 계정 삭제 운영

운영자: 우상영 / sangyoung2730@naver.com. 공개 기준은 신고 접수 후 24시간 이내 확인, 이메일 삭제 요청 7일 이내 처리, 완료된 문의·신고 이력 30일 뒤 삭제이다. 자동 신고 알림이나 예약 정리 작업은 현재 없다. 운영자는 매일 아래 절차를 실행해야 한다.

## 신고 확인과 조치

이 저장소 `firebase` 폴더에서 `npm ci` 후 기존에 승인한 Firebase CLI 계정으로 실행한다. 새 서비스 계정 키나 결제 요금제는 필요 없다. 출력에는 신고 내용이 포함될 수 있으므로 Git·공개 이슈에 붙이지 않는다.

```sh
NALDAM_OPERATOR_PROJECT=naldam-dev node scripts/moderate.mjs reports
NALDAM_OPERATOR_PROJECT=naldam-dev node scripts/moderate.mjs review 'contentReports/신고자UID/items/신고ID' inspect
```

신고와 관련 메시지·프로필만 확인한다. 신고자 정보를 상대에게 공개하지 않는다. 실제 내용을 확인한 뒤 다음 중 하나를 선택한다. 기본 실행은 미리보기이며, 변경 수를 확인한 다음 같은 명령에 `--apply`를 붙여 적용한다.

- `review '신고경로' remove-message`: 신고 대상 메시지를 삭제하고 처리 완료 기록.
- `review '신고경로' restrict`: 대상자의 발견·대화 쓰기를 제한하고 공개 프로필을 삭제. 계정 삭제와 문의는 계속 이용 가능.
- `review '신고경로' resolve`: 추가 조치 없이 확인 완료.
- `unrestrict '대상UID'`: 이의 제기 검토 후 제한 해제. 공개 프로필은 이용자가 다시 설정.

운영 도구는 실제 내용의 적절성을 자동으로 판단하지 않는다. 기본 단어 필터로 모든 유해 콘텐츠가 차단된다고 간주하지 않는다. 필요하면 Firebase Console에서 같은 문서 경로를 확인할 수 있다.

## 계정 삭제

앱의 홈 → 프로필 → 계정 삭제에서 본인 재인증 후 실행한다. Apple 계정은 인증 코드를 새로 받아 Firebase의 Apple 토큰 해제를 먼저 요청한다. 서버에 삭제 표식을 생성해 새 접촉을 막고, 참여한 방의 양측 메시지·상태·방, 본인의 차단·신고, 공개 프로필, 이 기기의 계정별 초안을 삭제한 다음 Auth 계정을 삭제한다. 일기·관심사·사진은 로그인 계정과 분리된 기기 데이터로 남는다고 확인 화면에 명시한다.

네트워크 중단 시 완료로 표시하지 않으며 같은 계정으로 재인증해서 이어서 삭제한다. 표식이 있는 동안 기존 계정으로 새 공개 프로필·대화·메시지를 만들 수 없다. 이메일로 요청한 경우 최소한의 본인 확인 후 동일 범위를 7일 이내 처리하고 이메일로 완료를 안내한다. 개인 Apple 비밀번호나 인증 코드는 요청하지 않는다.

## 보관 기간 정리

```sh
NALDAM_OPERATOR_PROJECT=naldam-dev node scripts/moderate.mjs cleanup
# 출력 확인 후
NALDAM_OPERATOR_PROJECT=naldam-dev node scripts/moderate.mjs cleanup --apply
```

매일 실행한다. 처리 완료 30일이 지난 신고만 삭제하며 미처리 신고는 남긴다. 삭제 표식은 Auth 사용자 부재·공개 프로필 부재·참여 방 부재를 확인한 시각을 먼저 기록한다. 그 시각으로부터 30일이 지난 뒤 다시 확인하고 표식, 상대방 차단 목록의 해당 UID, 이용 제한 표식을 정리한다. 원본 문서의 수정 시각을 조건으로 쓰므로 조회 이후 변경된 신고를 실수로 덮어쓰거나 지우지 않는다. 이미 지워진 자료는 복구할 수 없다.

문의 이메일은 처리 완료일을 별도로 기록하고 30일 뒤 메일 서비스에서 삭제한다. 운영 도구는 메일함을 읽거나 삭제하지 않는다. 법령상 예외 보존이 필요하면 사유·기간을 문서화하고 이용자에게 안내한다.
