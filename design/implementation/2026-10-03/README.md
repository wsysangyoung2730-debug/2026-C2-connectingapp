# 날담 구현 화면과 검증

PAPER 시안을 SwiftUI로 구현한 실제 iPhone 시뮬레이터 캡처입니다. 이미지 생성 시안이 아니라 자동 UI 테스트가 동작하는 앱에서 촬영한 화면입니다. 기록과 메시지 내용은 테스트 입력 및 샘플 데이터입니다.

## 확인한 결과

Xcode 26.5, iOS 26.5, iPhone 17 Pro 시뮬레이터에서 데이터 테스트 20개와 UI 테스트 4개가 모두 통과했습니다.

서명 없이 실제 iOS 기기용 Release 구성도 빌드에 성공했습니다. 이는 컴파일 검증이며 실기기 실행이나 배포 서명 검증을 뜻하지 않습니다.

- 날짜 경계와 윤년 달력, 같은 날짜 중복 저장 방지
- 원래 질문 보존, 임시 작성·수정·삭제, 저장 후 홈과 기록함 반영
- 기존 기록·관심사 스키마에서 임시 작성 모델을 추가한 뒤 디스크 데이터 보존
- 저장소를 다시 연 뒤 임시 작성과 샘플 메시지 복원
- 대화 요청 중복 방지, 수락 전 입력 제한, 차단·보관 시 메시지 유지
- 손상 파일과 지원하지 않는 버전의 원본 보존, 저장 실패 시 성공 상태 미표시
- 봉투 3단계 이동, 검색·선택·저장, 발견·대화 탭과 메시지 입력
- 온보딩 완료, 접근성용 큰 글자 설정에서 프로필과 관심사 편집 진입

UI 테스트는 메모리 기록 저장소, 임시 대화 파일, 별도 사용자 설정으로 격리했습니다. 일반 실행의 기록을 지우거나 샘플로 채우지 않습니다.

## 남은 확인

실제 사용자 간 통신은 구현되지 않았습니다. 서버·로그인·권한 검사·메시지 전달과 운영 체계가 필요합니다. 실제 기기, iPad, 가로 화면, VoiceOver 전체 사용 흐름은 별도 검증이 남아 있습니다. 자동 테스트 통과는 App Store 제출 준비 완료를 의미하지 않습니다.

현재 시스템의 기본 개발 도구 경로가 Command Line Tools라 테스트 종료 시 진단 수집용 simctl 경고가 있었지만, 테스트 자체는 성공했습니다. 빌드·테스트 명령은 Xcode 경로를 명시해 실행했습니다.
