이미지 안 인물명·대화·기록·활동 횟수는 설명을 위한 샘플입니다. 표시 날짜는 2026년 10월 2일 기준입니다.

## 핵심 디자인

- 하루의 질문에 답하고 기록하는 경험을 홈의 중심에 둡니다.
- 질문 카드와 본문은 불투명한 종이 면, 하단 탐색은 차분한 Liquid Glass 느낌으로 구분합니다.
- 커스텀 풀업은 기존 봉투 구조를 유지합니다. 접힌 상태의 종이·상 아바타·독서/산책/음악 태그가 같은 요소로 올라갑니다.
- 풀업 중간에는 편집 버튼도 있어 드래그 외의 진입 방법을 제공합니다.
- 완전히 펼친 관심사 편집은 배경을 흐리게 하여 집중 상태를 구분합니다.
- 기록 작성·기록 모음·일대일 대화 같은 상세 화면은 뒤로가기로 상위 화면에 돌아갑니다.
- 나만 보는 개인 기록과 발견에서 공개한 이야기를 구분합니다.

## 홈에서 추가한 제안

1. **이번 주, 세 번의 기록**: 연속 기록 압박보다 일주일 동안 쌓인 기록을 보여줍니다.
2. **다시 꺼내보는 나**: 예전 기록 한 장을 다시 읽고 나의 기록으로 들어갈 수 있는 입구입니다.
3. **임시 저장**: 작성 도중 나와도 이어서 쓸 수 있도록 편집 화면에서 상태를 알려주는 제안입니다.

이 기능은 이미지에 표현한 제품 제안이며 실제 앱에 구현한 상태는 아닙니다.

## 재질과 플랫폼 근거

[Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials)는 Liquid Glass를 탐색과 조작 영역에 사용하고 콘텐츠에는 사용하지 않도록 설명합니다. 이번 시안도 질문·기록 카드에는 종이 면을, 하단 탭바와 대화 입력 도구에는 반투명 재질을 사용합니다.

[Apple Tab bars](https://developer.apple.com/design/human-interface-guidelines/tab-bars)에 따라 최상위 탐색은 홈·발견·대화 세 목적지와 명확한 아이콘·라벨로 구성합니다.

[Apple Sheets](https://developer.apple.com/design/human-interface-guidelines/sheets)는 짧은 작업에 집중하는 편집 흐름을 안내합니다. 봉투 모양과 당겨 꺼내는 동작은 이 앱의 커스텀 디자인 제안입니다.

PNG만으로 네이티브 Liquid Glass 동작이나 제스처를 검증한 것은 아닙니다. 실제 구현 단계에서는 스크롤, 키보드, 글자 크기 확대, 투명도 줄이기, 동작 줄이기를 함께 확인합니다.

## 파일과 제작

- 내장 이미지 생성 도구로 만든 PNG 화면 시안입니다.
- [생성 프롬프트](prompts.json)에 각 화면의 정확한 지시문과 참조 역할을 보관했습니다.
- [풀업 수정 프롬프트](refinements.json)에 상태 간 아바타·태그 배치와 펼친 상태의 손잡이를 맞추는 후속 지시문을 보관했습니다.
- [기존 풀업 참고 이미지](legacy-pullup-reference.png)는 사용자가 제공한 디자인 자료입니다.
- [선택한 PAPER 브랜드 시안](../../branding/2026-10-02-naldam/01-page.png)을 색·로고 기준으로 사용했습니다.

홈 이미지를 먼저 만든 후, 나머지 화면에 같은 홈 이미지를 시각적 기준으로 전달하여 전체 톤을 맞췄습니다.

후속 생성 요청은 연결 오류로 실패했습니다. 02·03은 최초 생성본이며, 상태 간 요소 연속성 개선은 실제 코드에 반영합니다. 05 이미지 파일은 생성되지 않았습니다.
