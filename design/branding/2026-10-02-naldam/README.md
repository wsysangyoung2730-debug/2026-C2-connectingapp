# 날담 — 브랜드 1차 시안

상태: 사용자가 **01 PAPER 로고 시안**을 선택했습니다. 메인 메뉴는 **홈 · 발견 · 대화**로 확정됐으며, UI 이미지 시안은 작업명 날담과 01 PAPER의 종이 모양·테라코타 색을 기준으로 제작합니다.

## 브랜드의 기준

하루의 질문에 답하고 기록하며 나를 알아가는 경험 자체에 큰 가치가 있습니다. 관심사와 내가 공개한 이야기를 통해 사람을 발견하고, 원할 때 대화로 이어집니다. 다른 사람과 연결되지 않아도 개인 기록의 가치는 완결되어야 합니다.

기존 C2 메모는 기획 배경과 당시의 작업 기록으로 참고했습니다.

## 이름 제안

- 한글: **날담**
- 영문 표기 시안: **naldam**
- 뜻: **날마다 나를 담다**
- 브랜드 문장: **오늘의 나를 담다.**
- 기능 설명: **하루 한 질문으로 나를 알아가는 기록.**
- 연결 경험 설명: **나누고 싶은 이야기로, 새로운 대화를 시작해요.**
- 스토어 표시 이름 후보: **날담 - 하루 한 질문, 나의 기록**

‘날’은 하루하루를, ‘담’은 그날의 나를 담는 경험을 표현합니다. 채팅을 필수 사용 이유로 내세우지 않으며, 기록과 사람 사이의 대화가 자연스럽게 연결되도록 합니다.

## 네이밍 기준

| 위치 | 제안 문구 |
| --- | --- |
| 메인 메뉴 (확정) | 홈 · 발견 · 대화 |
| 홈 질문 | 오늘의 질문 |
| 기록 모음 | 나의 기록 |
| 질문 작성 진입 | 기록하기 |
| 작성 완료 | 기록 저장 |
| 기록 공개 범위 | 나만 보기 / 발견에 공개 |
| 발견 추천 이유 | 비슷한 관심사 |
| 상대 기록 | 공개한 이야기 |
| 첫 연락 | 대화 요청 |
| 채팅 전송 | 메시지 보내기 |
| 대화 목록 구분 | 받은 요청 / 대화 |

‘기록 저장’과 ‘공개’, ‘메시지 보내기’는 각각의 의미가 분명한 별도 행동으로 설계합니다. 개인 기록을 저장했다고 자동으로 다른 사람에게 보내지는 표현은 사용하지 않습니다.

## 로고 방향

| 시안 | 모티프 | 의도 |
| --- | --- | --- |
| 01 · PAPER | 작은 접힘이 있는 종이 한 장 | 사용자 선택안 · 매일 나를 기록하는 경험을 가장 직접적으로 전달 |
| 02 · ENVELOPE | 봉투에서 살짝 꺼낸 종이 | 비교안 · 기존 C2의 봉투 감성과 기록·대화를 함께 표현 |
| 03 · LAYERS | 겹쳐 쌓인 종이 | 하루하루 쌓이며 나를 알아가는 기록의 축적 |

세 시안은 서로 다른 탐색안입니다. 사용자가 선택한 01 방향을 UI에 적용하며, 최종 심볼과 앱 아이콘은 이 방향을 기준으로 다듬습니다.

01은 기록의 의미를 가장 직접적으로 표현합니다. 기존 C2의 봉투 감성은 로고에 모두 넣기보다, 사용자가 유지하기를 요청한 커스텀 풀업 패널에서 이어갑니다.

공통 배경은 아이보리, 글자색은 짙은 브라운입니다. 01은 테라코타, 02는 카라멜, 03은 차분한 올리브 계열로 비교합니다. 로고의 실제 출력색은 이미지 생성 결과에 따라 다를 수 있습니다.
